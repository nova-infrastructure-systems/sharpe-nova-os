# Start Here

## 1. What Nova does

Sharpe Nova OS structures governed review context for consequential
machine-prepared capital actions before local authority decides.

```text
Agent prepares an action.
Nova structures review context.
Local authority decides.
External systems execute.
Nova does not execute.
```

Nova is a pre-execution decision discipline layer that conditions capital
through telemetry, Reflex Memory, and constraint logic before execution.

## 2. The problem Nova addresses

An institution can have every document, source, rule, validation, and prior
record present while still lacking a coherent answer to:

- which evidence belongs to this exact action now;
- which constraint applies under these conditions;
- what changed materially;
- what prior context remains relevant;
- what remains unresolved;
- what local authority actually received before deciding.

Nova structures those relationships without becoming the approver or execution
layer.

## 4. Current planes

### Retail agent plane

A separately bounded public machine-commerce surface is active on Base mainnet
using USDC and x402 v2.

| Resource | Price | Job |
|---|---:|---|
| State Ping | 0.002 USDC | What context exists? |
| Context Delta | 0.02 USDC | What materially changed? |
| Governed Review Context | 0.10 USDC | What review context belongs around this exact proposed action? |
| Decision Context Packet | 1.00 USDC | What portable integrity-bound review artifact should local authority receive? |

Payment buys context access only.

It does not create approval, institutional identity, workflow authorization,
execution permission, or capital authority.

### Institutional plane

The target-v2 non-authority review-context contract remains the canonical
institutional direction.

The private synthetic target-v2 reference adapter is implemented, but the target
v2 runtime is not implemented or production-active. No institutional pilot is
established.

The retail and institutional planes must not be collapsed.

## 5. First bounded institutional workflow

The first bounded institutional workflow is an agent-prepared stablecoin
treasury action.

An agent may prepare one proposal and later revise its amount, destination,
timing, counterparty, assumptions, or evidence.

Nova is designed to preserve which exact proposal version local authority
reviewed, which evidence and source state were current, which institution-owned
constraints belonged to that action, and what remained unresolved at that
moment.
